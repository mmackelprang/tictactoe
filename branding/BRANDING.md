# TicTacToe 3D — brand guide

**Proposed display name:** TicTacToe 3D
**Tagline:** *N in a row, in three dimensions.*

## Why this name

The engine's whole point is boards beyond 3×3 — stacked layers, bigger grids, longer lines. The name says so.

## The mark

Two stacked board layers with a win line running straight through both.
